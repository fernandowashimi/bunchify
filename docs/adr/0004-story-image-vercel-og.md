# Story PNGs via @vercel/og / Satori

Story generation uses **`@vercel/og` (Satori → PNG)** at **1080×1920** (9:16). The canvas is a full-bleed gradient. Text, logos, ranks, and cover art stay inside the organic Story danger zone: **14%** top (269px), **20%** bottom (384px), and **6%** each side (65px). The renderer is not `chrome-aws-lambda` or a default Chromium path. Templates become JSX with embedded fonts (Syne, DM Sans, and italic Instrument Serif for the ranks); remote Spotify images stay runtime fetches. **`@sparticuz/chromium` + `puppeteer-core`** remains the documented escape hatch if a visual spike fails Satori fidelity or needs unsupported CSS. The first image implement step is that spike; reopen this ADR only if the escape hatch is chosen.
